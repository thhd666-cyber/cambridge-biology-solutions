大問252：楕円に引いた2本の接線の直交証明（接線の公式の利用）

傾き $m$ の接線公式・解と係数の関係・直交条件 $m_1 m_2 = -1$・モンジュの円（準円）

2次曲線・解析幾何
【問題】
点 $(3, 4)$ から楕円 $\frac{x^2}{16} + \frac{y^2}{9} = 1$ に引いた 2 本の接線は直交することを示せ。
接線の公式を用いた完全証明
正解・証明の完結 「傾きの積 $m_1 m_2 = -1$ より2本の接線は直交する（証明終了）」
図：楕円 $\frac{x^2}{16} + \frac{y^2}{9} = 1$、点 $\text{P}(3, 4)$ から引いた2本の直交接線、およびモンジュの円（準円 $x^2 + y^2 = 25$）
  • Step 1: 楕円の接線の公式の適用
    楕円 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（ここで $a^2 = 16, b^2 = 9$）において、傾きが $m$ である接線の方程式は： $$y = mx \pm \sqrt{a^2 m^2 + b^2} \iff y = mx \pm \sqrt{16m^2 + 9}$$ ※点 $(3, 4)$ を通る直線において、$x$ 軸に垂直な直線 $x = 3$ は楕円 $\frac{x^2}{16} + \frac{y^2}{9} = 1$ と $x = 3$ で $y = \pm \frac{3\sqrt{7}}{4} \neq 4$ より接線ではないため、接線の傾きを $m$ とおくことができます。
  • Step 2: 通る点 $(3, 4)$ の代入と $m$ の2次方程式の導出
    この接線が点 $(3, 4)$ を通るから、$x = 3, y = 4$ を代入すると： $$4 = 3m \pm \sqrt{16m^2 + 9}$$ 根号の項を分離すると： $$4 - 3m = \pm \sqrt{16m^2 + 9}$$ 両辺を2乗して根号を外すと： $$(4 - 3m)^2 = 16m^2 + 9$$ $$16 - 24m + 9m^2 = 16m^2 + 9$$ すべて右辺に移項して整理すると： $$7m^2 + 24m - 7 = 0$$
  • Step 3: 解と係数の関係と直交の判定
    $m$ についての2次方程式 $7m^2 + 24m - 7 = 0$ の判別式を $D$ とすると： $$\frac{D}{4} = 12^2 - 7 \times (-7) = 144 + 49 = 193 > 0$$ より、この方程式は異なる2つの実数解 $m_1, m_2$ をもちます（点 $(3, 4)$ から引ける2本の接線の傾きが存在する）。
    解と係数の関係より、2つの傾きの積 $m_1 m_2$ は： $$\mathbf{m_1 m_2 = \frac{-7}{7} = -1}$$ 2直線の傾きの積が $-1$ であるため、**点 $(3, 4)$ から引いた2本の接線は直交する**。（証明終了）
別解：接点の公式 $\frac{x_0 x}{16} + \frac{y_0 y}{9} = 1$ を用いる方法

楕円上の接点を $(x_0, y_0)$ とおくと、接線の方程式は $\frac{x_0 x}{16} + \frac{y_0 y}{9} = 1$ です。
この接線が点 $(3, 4)$ を通るため $\frac{3x_0}{16} + \frac{4y_0}{9} = 1$ が成り立ちます。
接線の傾きは $m = -\frac{9x_0}{16y_0}$ であり、これより $x_0 = -\frac{16m y_0}{9}$ を上の式に代入すると $y_0 = \frac{9}{4 - 3m}$、したがって $x_0 = -\frac{16m}{4 - 3m}$ が得られます。
点 $(x_0, y_0)$ は楕円上にあるため $\frac{x_0^2}{16} + \frac{y_0^2}{9} = 1$ に代入すると： $$\frac{1}{16}\left(\frac{-16m}{4-3m}\right)^2 + \frac{1}{9}\left(\frac{9}{4-3m}\right)^2 = 1 \iff 16m^2 + 9 = (4 - 3m)^2 \iff 7m^2 + 24m - 7 = 0$$ 同様に $m_1 m_2 = -1$ となり直交することが示されます。

発展：モンジュの円（準円 / Director Circle）の定理

一般に、楕円 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ に対して引いた2本の接線が直交するような点 $(x, y)$ の軌跡は、円： $$x^2 + y^2 = a^2 + b^2$$ となります。これをモンジュの円（準円）と呼びます。
本問では $a^2 = 16, b^2 = 9$ であるため、準円の方程式は $x^2 + y^2 = 16 + 9 = 25$ です。
与えられた点 $(3, 4)$ は $3^2 + 4^2 = 9 + 16 = 25$ を満たすため、まさにモンジュの円周上の点です。したがって、ここから引いた2本の接線は必然的に直交します。

大問183：1の $2n$ 乗根と等比数列の和・代数学の基本定理

極形式・ド・モアブルの定理・等比数列の和の公式・方程式 $z^{2n} = 1$ の解の完全決定

複素数平面・方程式論
【問題】
$n$ を自然数とし，$\alpha = \cos\frac{\pi}{n} + i\sin\frac{\pi}{n}$ とする。次の問いに答えよ。
(1) $1 + \alpha + \alpha^2 + \dots + \alpha^{2n-1}$ の値を求めよ。
(2) $z^{2n} = 1$ の解は $1, \alpha, \alpha^2, \dots, \alpha^{2n-1}$ であることを示せ。
(1) $1 + \alpha + \alpha^2 + \dots + \alpha^{2n-1}$ の値の算出
正解・結論 $$0$$

$\alpha^{2n} = \cos 2\pi + i\sin 2\pi = 1$ かつ $\alpha \neq 1$ より：
$$1 + \alpha + \dots + \alpha^{2n-1} = \frac{1 - \alpha^{2n}}{1 - \alpha} = \frac{1 - 1}{1 - \alpha} = \mathbf{0}$$

(2) $z^{2n} = 1$ の解の決定証明
正解・証明の完結 「相異なる2n個の解が存在し、方程式の次数と一致するため（証明終了）」

$(\alpha^k)^{2n} = 1$ より各 $\alpha^k$ は解。偏角の差 $0 < \frac{(k-j)\pi}{n} < 2\pi$ より相異なる $2n$ 個の解が存在し、代数学の基本定理よりこれらですべて尽くされます。

第4問(2)：数列の和 $S_n$ と一般項 $a_n$ の関係式

和と一般項の関係 $a_n = S_n - S_{n-1}$・平方完成と2次方程式・等差数列への帰着

数列と漸化式
【問題】
$a_n > 0 \ (n = 1, 2, 3, \dots)$ となる数列 $\{a_n\}$ の初項から第 $n$ 項までの和 $S_n$ が $S_n = \frac{a_n}{2} + \frac{2}{a_n}$ で表されるとき，
(1) $a_1$ を求めよ。 (2) $S_n$ を求めよ。 (3) 数列 $\{a_n\}$ の一般項を求めよ。
解答・まとめ $$a_1 = 2, \quad S_n = 2\sqrt{n}, \quad a_n = 2(\sqrt{n} - \sqrt{n-1})$$
