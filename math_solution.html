🎨 内サイクロイド リアルタイム軌跡描画シミュレータ

円 $\text{C}$ が転がるにつれて、点 $\text{P}$ がリアルタイムに軌跡を描いていきます。
比率 $a : b = n : 1$ の $n$ の値をスライダーやプリセットボタンで変更して、様々な内サイクロイドの軌跡を観察できます。

n = 3.0 (a:b = 3:1 デルトイド)
プリセット:
曲線の名称 デルトイド（三尖形）
尖点（カプス）の数 3 個
回転角 $\theta$ 0.00 rad

💡 各問の詳細解説・計算導出

📌 (1) 3倍角の公式の導出

加法定理と2倍角の公式より導出します。

$$\begin{aligned} \cos 3\alpha &= \cos(2\alpha + \alpha) = \cos 2\alpha \cos\alpha - \sin 2\alpha \sin\alpha \\ &= (2\cos^2\alpha - 1)\cos\alpha - (2\sin\alpha\cos\alpha)\sin\alpha \\ &= 2\cos^3\alpha - \cos\alpha - 2\cos\alpha(1 - \cos^2\alpha) \\ &= \mathbf{-3\cos\alpha + 4\cos^3\alpha} \quad \implies \fbox{ア} = -3, \ \fbox{イ} = 4 \end{aligned}$$
$$\begin{aligned} \sin 3\alpha &= \sin(2\alpha + \alpha) = \sin 2\alpha \cos\alpha + \cos 2\alpha \sin\alpha \\ &= (2\sin\alpha\cos\alpha)\cos\alpha + (1 - 2\sin^2\alpha)\sin\alpha \\ &= 2\sin\alpha(1 - \sin^2\alpha) + \sin\alpha - 2\sin^3\alpha \\ &= \mathbf{3\sin\alpha - 4\sin^3\alpha} \quad \implies \fbox{ウ} = 3, \ \fbox{エ} = -4 \end{aligned}$$
📌 (2) $\angle\text{BCP}$ の大きさ

円 $\text{C}$ は円 $\text{O}$ の内側を「すべることなく」転がるため、円 $\text{O}$ 上の弧 $\text{AB}$ の長さ と 円 $\text{C}$ 上の弧 $\text{BP}$ の長さ は等しくなります。

$$\text{弧 AB の長さ} = a \theta$$ $$\text{弧 BP の長さ} = b \times \angle\text{BCP}$$

$\text{弧 AB} = \text{弧 BP}$ より、

$$a\theta = b \angle\text{BCP} \implies \mathbf{\angle\text{BCP} = \frac{a}{b}\theta}$$
📌 (3) 点 $\text{P}$ の座標 $(x, y)$ の媒介変数表示

ベクトルの和として $\vec{\text{OP}} = \vec{\text{OC}} + \vec{\text{CP}}$ を求めます。

① 中心 $\text{C}$ の位置ベクトル $\vec{\text{OC}}$:
線分 $\text{OC} = a - b$ であり、$\angle\text{COA} = \theta$ であるから：

$$\vec{\text{OC}} = \big( (a-b)\cos\theta, \ (a-b)\sin\theta \big)$$

② ベクトル $\vec{\text{CP}}$ の向き（偏角）:
中心 $\text{C}$ から接点 $\text{B}$ への向きの偏角は $\theta$ です。
円 $\text{C}$ は時計回り（負の方向）に自転するため、$\vec{\text{CP}}$ は $\vec{\text{CB}}$ から時計回りに $\angle\text{BCP} = \frac{a}{b}\theta$ 回転した向きになります。
したがって、$\vec{\text{CP}}$ の $x$ 軸正の向きとなす偏角 $\phi$ は：

$$\phi = \theta - \frac{a}{b}\theta = -\frac{a-b}{b}\theta$$

$|\vec{\text{CP}}| = b$ より、

$$\vec{\text{CP}} = \left( b\cos\left(-\frac{a-b}{b}\theta\right), \ b\sin\left(-\frac{a-b}{b}\theta\right) \right) = \left( b\cos\left(\frac{a-b}{b}\theta\right), \ -b\sin\left(\frac{a-b}{b}\theta\right) \right)$$

以上を足し合わせて：

$$\mathbf{x = (a-b)\cos\theta + b\cos\left(\frac{a-b}{b}\theta\right)}$$ $$\mathbf{y = (a-b)\sin\theta - b\sin\left(\frac{a-b}{b}\theta\right)}$$
📌 (4) $a : b = 4 : 1$ のとき（アステロイド）

$b = \frac{a}{4}$、$a - b = \frac{3}{4}a$、$\frac{a-b}{b} = 3$ を代入します。

$$x = \frac{3}{4}a\cos\theta + \frac{1}{4}a\cos 3\theta = \frac{a}{4}(3\cos\theta + \cos 3\theta)$$ $$y = \frac{3}{4}a\sin\theta - \frac{1}{4}a\sin 3\theta = \frac{a}{4}(3\sin\theta - \sin 3\theta)$$

(1) より $3\cos\theta + \cos 3\theta = 4\cos^3\theta$、$3\sin\theta - \sin 3\theta = 4\sin^3\theta$ であるから：

$$x = a\cos^3\theta, \quad y = a\sin^3\theta$$

$\cos^2\theta + \sin^2\theta = 1$ に代入して $\theta$ を消去すると：

$$\left(\frac{x}{a}\right)^{\frac{2}{3}} + \left(\frac{y}{a}\right)^{\frac{2}{3}} = 1 \iff \mathbf{x^{\frac{2}{3}} + y^{\frac{2}{3}} = a^{\frac{2}{3}}}$$

【曲線の長さ $L$ の計算】:
アステロイドは4つの象限で合同に対称であるため、第1象限（$0 \le \theta \le \pi/2$）の長さを4倍します。

$$\frac{dx}{d\theta} = -3a\cos^2\theta\sin\theta, \quad \frac{dy}{d\theta} = 3a\sin^2\theta\cos\theta$$ $$\left(\frac{dx}{d\theta}\right)^2 + \left(\frac{dy}{d\theta}\right)^2 = 9a^2\cos^2\theta\sin^2\theta(\cos^2\theta+\sin^2\theta) = 9a^2\sin^2\theta\cos^2\theta$$

$0 \le \theta \le \pi/2$ では $\sin\theta\ge 0, \cos\theta\ge 0$ より：

$$L = 4 \int_{0}^{\frac{\pi}{2}} 3a\sin\theta\cos\theta \, d\theta = 12a \left[ \frac{1}{2}\sin^2\theta \right]_0^{\frac{\pi}{2}} = 12a \times \frac{1}{2} = \mathbf{6a}$$
📌 (5) $a : b = 3 : 1$ のとき（デルトイド）

$b = \frac{a}{3}$、$a - b = \frac{2}{3}a$、$\frac{a-b}{b} = 2$ を代入します。

$$x = \frac{2}{3}a\cos\theta + \frac{1}{3}a\cos 2\theta = \frac{a}{3}(2\cos\theta + \cos 2\theta)$$ $$y = \frac{2}{3}a\sin\theta - \frac{1}{3}a\sin 2\theta = \frac{a}{3}(2\sin\theta - \sin 2\theta)$$

【曲線の長さ $L$ の計算】:

$$\frac{dx}{d\theta} = -\frac{2}{3}a(\sin\theta + \sin 2\theta), \quad \frac{dy}{d\theta} = \frac{2}{3}a(\cos\theta - \cos 2\theta)$$ $$\begin{aligned} \left(\frac{dx}{d\theta}\right)^2 + \left(\frac{dy}{d\theta}\right)^2 &= \frac{4}{9}a^2 \Big[ (\sin^2\theta + 2\sin\theta\sin 2\theta + \sin^2 2\theta) + (\cos^2\theta - 2\cos\theta\cos 2\theta + \cos^2 2\theta) \Big] \\ &= \frac{4}{9}a^2 \Big[ 2 - 2(\cos 2\theta\cos\theta - \sin 2\theta\sin\theta) \Big] \\ &= \frac{4}{9}a^2 (2 - 2\cos 3\theta) = \frac{8}{9}a^2(1 - \cos 3\theta) = \frac{16}{9}a^2\sin^2\left(\frac{3\theta}{2}\right) \end{aligned}$$

デルトイドは周期 $\frac{2\pi}{3}$ で3つの合同な弧を持つため、$0 \le \theta \le \frac{2\pi}{3}$ の長さを3倍します（この区間で $\sin\frac{3\theta}{2}\ge 0$）。

$$L = 3 \int_{0}^{\frac{2\pi}{3}} \frac{4}{3}a \sin\left(\frac{3\theta}{2}\right) \, d\theta = 4a \left[ -\frac{2}{3}\cos\left(\frac{3\theta}{2}\right) \right]_0^{\frac{2\pi}{3}} = 4a \left( \frac{2}{3} - \left(-\frac{2}{3}\right) \right) = 4a \times \frac{4}{3} = \mathbf{\frac{16}{3}a}$$

【囲まれた部分の面積 $S$ の計算】:
媒介変数による面積公式 $S = \frac{1}{2}\int_{0}^{2\pi} \left(x \frac{dy}{d\theta} - y \frac{dx}{d\theta}\right) d\theta$ を用います。

$$\begin{aligned} x\frac{dy}{d\theta} - y\frac{dx}{d\theta} &= \frac{a^2}{9} \Big[ (2\cos\theta+\cos 2\theta)(2\cos\theta-2\cos 2\theta) - (2\sin\theta-\sin 2\theta)(-2\sin\theta-2\sin 2\theta) \Big] \\ &= \frac{a^2}{9} \Big[ 4(\cos^2\theta+\sin^2\theta) - 2(\cos^2 2\theta+\sin^2 2\theta) - 2(\cos 2\theta\cos\theta - \sin 2\theta\sin\theta) \Big] \\ &= \frac{a^2}{9} (4 - 2 - 2\cos 3\theta) = \frac{2a^2}{9}(1 - \cos 3\theta) \end{aligned}$$

したがって、

$$S = \frac{1}{2} \int_{0}^{2\pi} \frac{2a^2}{9}(1 - \cos 3\theta) \, d\theta = \frac{a^2}{9} \left[ \theta - \frac{\sin 3\theta}{3} \right]_0^{2\pi} = \frac{a^2}{9} \times 2\pi = \mathbf{\frac{2}{9}\pi a^2}$$
📖 問題 (4)
実数 $x$ の関数 $\displaystyle f(x) = \sum_{k=1}^{N} |x - k|$ について、この関数の最小値を求めよ。
また、そのときの $x$ を求めよ。ただし、$N$ は自然数とする。
模範解答
① $N$ が奇数のとき
最小値：
$\displaystyle \frac{N^2 - 1}{4}$
そのときの $x$：
$\displaystyle x = \frac{N + 1}{2}$
② $N$ が偶数のとき
最小値：
$\displaystyle \frac{N^2}{4}$
そのときの $x$：
$\displaystyle \frac{N}{2} \le x \le \frac{N}{2} + 1$
