(e) 過酸化水素とクロムの標準電池起電力および $\Delta G^\ominus$ [3 marks]
The $E^\ominus$ values for two electrode reactions are given.
$\text{H}_2\text{O}_2 + 2\text{H}^+ + 2\text{e}^- \rightleftharpoons 2\text{H}_2\text{O} \quad E^\ominus = +1.77\text{ V}$
$\text{Cr}^{3+} + \text{e}^- \rightleftharpoons \text{Cr}^{2+} \quad E^\ominus = -0.41\text{ V}$

An electrochemical cell is constructed with the following half-cells (electrodes):

$\text{H}_2\text{O}_2 + 2\text{H}^+ + 2\text{e}^- \rightleftharpoons 2\text{H}_2\text{O} \quad E^\ominus = +1.77\text{ V}$
$\text{Cr}^{3+} + \text{e}^- \rightleftharpoons \text{Cr}^{2+} \quad E^\ominus = -0.41\text{ V}$

次の半電池（電極）を用いて化学電池を構築した：
・酸性化された $\text{H}_2\text{O}_2$ 溶液と白金線

正解 (Answer & Official Mark Scheme) [1 Mark]
日本語解答
• 正極: $\text{H}_2\text{O}_2$ / $\text{H}_2\text{O}$ 半電池（または酸性化 $\text{H}_2\text{O}_2$）

Official English Mark Scheme

• $E^\ominus_{\text{cell}} = \mathbf{+2.18\text{ V}}$ (or $2.18\text{ V}$)

💡 解説と導出プロセス

  • 正極の判定： より高い（正の大きい）標準電極電位を持つ半電池が還元反応を起こすカソード（正極、positive electrode）となります。
    $E^\ominus(\text{H}_2\text{O}_2/\text{H}_2\text{O}) = +1.77\text{ V} > E^\ominus(\text{Cr}^{3+}/\text{Cr}^{2+}) = -0.41\text{ V}$ であるため、$\text{H}_2\text{O}_2$ 半電池が正極です。

💡 解説と計算手順

  • 電池全体の反応式と移動電子数 $n$ の決定：
    正極（還元）：$\text{H}_2\text{O}_2 + 2\text{H}^+ + 2\text{e}^- \rightarrow 2\text{H}_2\text{O}$
    負極（酸化）：$2\text{Cr}^{2+} \rightarrow 2\text{Cr}^{3+} + 2\text{e}^-$
    全体反応：$\text{H}_2\text{O}_2 + 2\text{H}^+ + 2\text{Cr}^{2+} \rightarrow 2\text{H}_2\text{O} + 2\text{Cr}^{3+}$
    したがって、$\text{H}_2\text{O}_2$ 1 mol が反応するとき移動する電子物質量は $n = 2\text{ mol}$。
  • 公式への代入：
    $\Delta G^\ominus = -n F E^\ominus_{\text{cell}}$ を用いる（ファラデー定数 $F = 96500\text{ C mol}^{-1}$）。 $$\Delta G^\ominus = -2 \times 96500\text{ C mol}^{-1} \times 2.18\text{ V} = -420740\text{ J mol}^{-1} = \mathbf{-421\text{ kJ mol}^{-1}}$$
⚠️ 注意・落とし穴 単位は $\text{kJ mol}^{-1}$ を要求されているため、計算結果の $\text{J}$ を $1000$ で割ることを絶対に忘れないでください。また、自発的反応であるため符号は必ずマイナス（$-$）になります。
(f) ネルンストの式による電位計算と非標準状態での電池反応 [3 marks]
The $E^\ominus$ values for two electrode reactions are given.
$\text{H}_2\text{O}_2 + 2\text{H}^+ + 2\text{e}^- \rightleftharpoons 2\text{H}_2\text{O} \quad E^\ominus = +1.77\text{ V}$
$\text{Co}^{3+} + \text{e}^- \rightleftharpoons \text{Co}^{2+} \quad E^\ominus = +1.82\text{ V}$

An electrochemical cell is constructed with the following half-cells.
half-cell 1: an acidified solution of $\text{H}_2\text{O}_2$ under standard conditions, a platinum wire
half-cell 2: a solution containing $0.020\text{ mol dm}^{-3}\text{ Co}^{3+}$ and $2.0\text{ mol dm}^{-3}\text{ Co}^{2+}$, a platinum wire

$\text{H}_2\text{O}_2 + 2\text{H}^+ + 2\text{e}^- \rightleftharpoons 2\text{H}_2\text{O} \quad E^\ominus = +1.77\text{ V}$
$\text{Co}^{3+} + \text{e}^- \rightleftharpoons \text{Co}^{2+} \quad E^\ominus = +1.82\text{ V}$

次の半電池からなる化学電池を構築した：
半電池 1: 標準状態における酸性 $\text{H}_2\text{O}_2$ 溶液、白金線
半電池 2: $0.020\text{ mol dm}^{-3}$ の $\text{Co}^{3+}$ と $2.0\text{ mol dm}^{-3}$ の $\text{Co}^{2+}$ を含む溶液、白金線

(i) ネルンストの式による半電池 2 の電極電位 $E$ の算出 [2 marks]

Use the Nernst equation to calculate the value of $E$, the electrode potential of half-cell 2 under these conditions.

正解 (Answer & Official Mark Scheme) [2 Marks]
日本語解答
$E = $ +1.70 V （または +1.702 V）
Official English Mark Scheme
$E = \mathbf{+1.70\text{ V}}$ (or $\mathbf{+1.702\text{ V}}$)
[M1: $\log_{10}(0.020 / 2.0) = -2$; M2: $1.82 + 0.059(-2) = +1.70\text{ V}$]

💡 解説と計算手順

ネルンストの式（Cambridgeシラバス形式）：
$$E = E^\ominus + \frac{0.059}{z} \log_{10} \frac{[\text{oxidised species}]}{[\text{reduced species}]}$$
  • 電極反応：$\text{Co}^{3+} + \text{e}^- \rightleftharpoons \text{Co}^{2+}$ なので、酸化型は $\text{Co}^{3+}$、還元型は $\text{Co}^{2+}$、電子数 $z = 1$ です。
  • 数値を代入： $$E = +1.82 + \frac{0.059}{1} \log_{10}\left(\frac{0.020}{2.0}\right)$$
  • 対数部分の計算： $$\frac{0.020}{2.0} = 0.010 = 10^{-2} \implies \log_{10}(10^{-2}) = -2$$
  • 最終電位： $$E = +1.82 + 0.059 \times (-2) = +1.82 - 0.118 = \mathbf{+1.702\text{ V} \approx +1.70\text{ V}}$$

(ii) この条件下で起こる電池反応の化学反応式 [1 mark]

Write an equation for the cell reaction that occurs in this cell under these conditions.
この条件下において、この電池内で起こる電池反応の反応式を記せ。
正解 (Answer & Official Mark Scheme) [1 Mark]
日本語解答
$\text{H}_2\text{O}_2 + 2\text{H}^+ + 2\text{Co}^{2+} \rightarrow 2\text{H}_2\text{O} + 2\text{Co}^{3+}$
Official English Mark Scheme
$\text{H}_2\text{O}_2 + 2\text{H}^+ + 2\text{Co}^{2+} \rightarrow 2\text{H}_2\text{O} + 2\text{Co}^{3+}$

💡 最重要ポイント：濃度の影響による自発性の「逆転」

  • 標準状態（Standard conditions）の場合：
    $E^\ominus(\text{Co}^{3+}/\text{Co}^{2+}) = +1.82\text{ V} > E^\ominus(\text{H}_2\text{O}_2/\text{H}_2\text{O}) = +1.77\text{ V}$
    標準状態であれば $\text{Co}^{3+}$ が還元され、$\text{H}_2\text{O}_2$ が酸化されて $\text{O}_2$ を生じるはずでした。
  • 今回の非標準状態の場合：
    半電池 2 の電位は濃度変化により $E_2 = \mathbf{+1.70\text{ V}}$ に低下しました！
    一方、半電池 1 は標準状態なので $E_1 = \mathbf{+1.77\text{ V}}$ のままです。
    電位を比較すると、$E_1 (+1.77\text{ V}) > E_2 (+1.70\text{ V})$ となり、電位の大小関係が逆転しています！
  • したがって、電位の高い半電池 1（$\text{H}_2\text{O}_2$）が還元を受け、半電池 2（$\text{Co}^{2+}$）が酸化されます：
    還元（正極）：$\text{H}_2\text{O}_2 + 2\text{H}^+ + 2\text{e}^- \rightarrow 2\text{H}_2\text{O}$
    酸化（負極）：$2\text{Co}^{2+} \rightarrow 2\text{Co}^{3+} + 2\text{e}^-$
    全反応式：$$\mathbf{\text{H}_2\text{O}_2 + 2\text{H}^+ + 2\text{Co}^{2+} \rightarrow 2\text{H}_2\text{O} + 2\text{Co}^{3+}}$$
